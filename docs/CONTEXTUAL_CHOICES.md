# Choices from the current perspective

The native Claude reflection adapter now builds its output schema from the same
frozen pawn perspective used for its prompt and contextual executable-choice list.
No running agreement means no withdrawal or rescue-alternative request branch.
Available agreement IDs are exact constants; casualty target IDs and eligible
pending proposal IDs are enumerated. Continuing unchanged always remains valid.
This slice does not change the separate proposal-decision/counterproposal schema.

Optional private outlook revisions specify the current revision and only owned,
supplied evidence sequences (including evidence retained with prior notes).
Value/concern notes cannot name a subject. Stances require a supplied subject;
runtime validation still requires that subject to occur in the actually cited
evidence. An empty existing outlook can remain empty without fabricated evidence.
The schema does not judge the truth of interpretations or force an update.

Provider constraints are not authority. Strict parsing, contextual validation,
current revision checks and coordinator timeline/consent checks remain in place.
A malformed or stale reply must not be reinterpreted from its prose. Returned
provider choices and known usage are retained even when scope validation fails.
